# FRACTURE — Glass Touch (Ver.2)

スマートフォン／PCブラウザで動作する、ガラスのひび割れ表現アプリです。

## Ver.2の追加機能
- ヒビの周囲に白い反射・グローを描画
- 三角形・多角形の半透明なガラス片を表示
- タップ時に対応端末で微細な振動（Vibration API）
- 亀裂を画面端方向まで伸ばす演出
- 端末の傾きセンサーに応じて破片をわずかに動かす演出


## 注意
- 振動は対応するスマートフォン／ブラウザでのみ動作します。iPhoneではブラウザやOSの制限により振動できない場合があります。
- 傾きセンサーは端末・ブラウザによって許可操作が必要です。iOSでは最初の画面タップ後に許可ダイアログが出る場合があります。
- PCでは傾きセンサーがないため、破片の傾き連動は動作しません。
- 実機のiPhone／Androidでの動作確認は未実施です。
